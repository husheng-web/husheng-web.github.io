# AI Product Portfolio

Bilingual portfolio foundation for an AI Product Builder / Intelligent Service System Designer.

## Prerequisites

- Node.js 20.9 or newer (this workspace uses Node 24.14.1)
- npm

This repository uses a project-local npm cache (`.npm-cache/`) so package installation does not mutate the user cache. If the host injects a stale proxy, run npm with `HTTP_PROXY`, `HTTPS_PROXY` unset and `NPM_CONFIG_OFFLINE=false`.

## Commands

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
npm run format:check
```

## Content policy

Project facts, media, biography, contact information, and translations are added only after owner approval. Missing values render as explicit pending content rather than invented claims.
