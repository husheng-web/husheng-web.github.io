# 拼旅途 Behance Visual Reference Audit

## Reference observations

Reference inspected: [爱鼻e站 Visual direction, Qasim Qi](https://www.behance.net/gallery/167764471/e_Visual-direction).

- The long page alternates quiet text zones with oversized product interfaces, then reduces density before the next product beat.
- Screens are not treated as a uniform gallery. It uses isolated hero interfaces, paired screens, partial crops, and grouped UI sequences according to the story being told.
- Large whitespace gives high-contrast product UI room to become the visual subject, while smaller annotations remain subordinate.
- Scale changes rather than new decorative elements create the rhythm: large interface, smaller detail, pair, then quiet text.
- Product logic and visual proof alternate. The reference does not require every section to contain a diagram and a gallery.

## Applicable to 拼旅途

- Retain the portfolio's off-white editorial ground and use the existing black-gold product UI as the strongest color contrast.
- Make Generate to Compose the only oversized typographic concept moment.
- Use the Feed as an entrance image, Chapter plus a focused evidence crop, a Selection context plus TravelBlock detail, aligned Canvas comparison, and a large Companion image.
- Keep text in the reading column while allowing media to enter wide or full-bleed regions.
- Establish a low to high to low density sequence: Hero and Context, Reframing, Model, Experience, Building, Reflection.

## Do not copy

- No reference brand palette, illustrated mascot, rounded mobile device shell, or promotional poster hierarchy.
- No static desktop composition, absolute-positioned collage, image-over-text treatment, or decorative gradient field.
- No repeated soft background changes. 拼旅途 remains an evidence-led product case study, not an app campaign page.
