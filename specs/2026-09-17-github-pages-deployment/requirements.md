# GitHub Pages 部署需求

## 目标

将当前个人作品集发布到 `https://husheng-web.github.io`。

## 可观察行为

- 中文、英文首页及主要导航页面可直接访问。
- 项目详情页可静态访问。
- 项目 PDF 不进入公开仓库，也不显示下载入口。
- 简历图片与小体积简历 PDF 保持可用。
- 推送默认分支后由 GitHub Actions 自动部署 Pages。

## 约束

- 仓库名必须为 `husheng-web.github.io`。
- 不上传本地参考素材、原型备份、浏览器缓存、视觉验收截图或飞书应用目录。
- 不修改自定义域名设置。

## 范围外

- 项目 PDF 的压缩、外部托管与恢复入口。
- 自定义域名绑定。
- 飞书应用删除。
