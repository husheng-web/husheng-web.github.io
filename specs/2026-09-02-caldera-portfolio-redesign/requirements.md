# Caldera-inspired portfolio redesign

## Goal

Rework the existing bilingual portfolio into an original, Caldera-inspired visual system while preserving verified resume and project content.

## Observable behavior

- The home page uses a warm pumice canvas, ember-orange action color, plasma-violet accent surface, large compact display type, flat outlined cards, and pill controls.
- The home hero includes an original raster halftone portrait asset, an oversized Chinese/English headline, and working routes to projects and profile content.
- Profile, project archive, and shared header inherit the same tokens and geometry.
- Navigation, mobile menu, locale switch, and primary links continue to function.

## Constraints

- Use Caldera only as visual inspiration; do not copy its logo, code, copy, or assets.
- Keep supplied project and resume facts intact. Do not introduce invented metrics or personal contact data.
- Use actual image assets for visible illustration/hero artwork rather than CSS-drawn substitutes.

## Out of scope

- New backend, CMS, authentication, or deployment.
